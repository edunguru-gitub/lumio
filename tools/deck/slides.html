How it works · since stage I

Works offline today. Now also live on the web.

What works today (v1, the app in this video)

  • 8 lessons in 4 subjects, English and Romanian, 6 themes.
  • Runs offline. One HTML file (about 0.9 MB). No account; progress stays in the browser.
  • Handwriting recognition (template matching, not AI). Write a number with your finger; digits only.
  • Phone as controller. QR code on the local network; sliders and tilt drive the lab. Needs Lumio.cmd (Node.js) on the laptop.
Demo in this video = v1

What v2 adds for the user

  • Live on the web: edunguru-gitub.github.io/lumio (checked 26 Nov 2026). The web page alone only syncs two tabs; to use a phone, run Lumio.cmd on the laptop.
  • One module per lesson. A new lesson is one new file; removing one breaks nothing else.
  • 7 lessons, all rebuilt from v1 and checked against it: algebra, parabola, linear functions, Pythagoras, gas, projectile, compound interest.
  • Kept from v1: handwriting pad, phone controller, Levels, Challenge, Lumens, Moon ranks (New Moon to Blue Moon), Ranks, Settings, Light and Dark.
Not in v2 yet: Spanish verbs and vocabulary, podcast mode, 6 colour themes
AI and data, honestly

Built with AI, not sold as AI.

AI in the product today

None, except read-aloud: the browser’s built-in text-to-speech. Handwriting recognition (template matching, not AI) is our own code and works offline.

AI in how we build it

Claude agents (builder, designer, tester) write and check the code; the tester checks every port against v1. A human reviews every change.

Where data lives today

Progress: in the browser on the device (localStorage). No accounts, no server database. Phone link: a relay on the laptop, local network only. Class dashboard, parent updates and a hosted relay are plans, not built.

Next, only where AI adds value

Plan: a hint tutor that tells a stuck student what to try next. Hints, not answers. Only with parental consent. Not built yet.

Today: no cloud AI · no accounts · no server database
Business model

Free to learn. Private schools pay.

Key partners, activities, resources

Teachers and schools for the pilot; no signed partners yet. We build lessons and learn from teacher feedback, with an AI-assisted build.

Value proposition

Learn by doing: short hands-on labs, EN and RO. Today: YouTube, tutors, textbooks. Unlike PhET, Brilliant or Khan Academy, your phone controls the experiment (as far as we found).

Students: social media and teachers; free. Private schools: direct, an introduction, a pilot, then onboarding and teacher training.
