# Psychologist review
1. First 10 seconds: is there one obvious next action? Empty states must guide, not show a wall of dashes.
2. Motivation: ratings and rewards must start generous and honest; never show a discouraging number before enough data; give a first reward in under 30 seconds.
3. Overload: max one primary card plus three stats on Home; move the rest behind tabs.
4. Navigation: Home | Subjects | Ranks always visible; toggles Galaxy/Tabs, Light/Dark, RO/EN reachable in one tap, also on phone.
5. Tone: no slogans or quotes; plain labels; Romanian and English both natural.
6. Output: top 5 findings, each with a concrete fix, ordered by impact. No code edits.
