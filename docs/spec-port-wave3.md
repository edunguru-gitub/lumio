Learning objective (draft for the Professor): "You will be able to read a limit from a table and a graph, tell one-sided limits apart, and say when a limit exists."
Lab behaviour (the one idea: approach a, watch f):
- Canvas (cols 4-9, 360 high at 1273; 280 at 390): function graph in sage 2.5 px, axes and grid via U.gridMap, the point x = a marked by a thin ink vertical, an open ring where f(a) is undefined, and the limit level as a dashed muted horizontal line. Two approach markers: left (x = a - d) and right (x = a + d) as ink dots with labels "a-" and "a+" (letters and glyph shape, not colour alone).
- Controls (right column): preset chips (6 starter functions, final list by the Professor): (x^2 - 1)/(x - 1) at a = 1 (hole, limit 2); sin x / x at 0 (limit 1); 1/x at 0 (one-sided -inf and +inf, no limit); |x| / x at 0 (one-sided -1 and +1, jump); 1/x^2 at 0 (+inf both sides); (2x + 1)/(x - 3) as x -> +inf (limit 2). Distance d as a detent slider (spec-tactile) with 7 stops 1, .5, .1, .05, .01, .005, .001 (mono value, arrows = 1 step); side capsule Left | Both | Right (32 / 44); for the infinity preset the slider is "x" with stops 10, 100, 1000, 10^4, 10^5.
- Table (hairline, mono): rows for x = a -/+ d, a -/+ d/2, a -/+ d/10 with f(x) to 6 decimals; values over 10^6 print "-> +inf" / "-> -inf"; undefined prints "undefined" (never NaN); the row of the current d is highlighted (ink weight 600 plus left rule), never colour alone.
- Graph zoom: the view window is centred on (a, L) and shrinks with d (window half-width = max(3d, .02)) with a 300 ms ease; a "Zoom out" ghost button (32 / 44) returns to the full view; wheel and pinch do nothing (taste: one level per gesture); Reduce motion: instant.
- Read-out (aria-live): "from the left f -> 2 . from the right f -> 2 . limit = 2" or "limit does not exist (left -inf, right +inf)", computed from the preset's exact left / right values, not from the numeric table, so it never misreports. A line "f(a) is undefined, the limit still exists" or "f(a) = 5 but the limit is 2" appears when it applies (the main misconception: limit is not f(a)).
- Exercises (4 to 5, order and wording by the Professor; Lumens +10 each, +15 all, ctx.report({qt})): read the limit at the hole preset (type, accepted set stated); one-sided limit of the jump preset; "exists / does not exist" choice for 1/x with the reason chosen from 3; limit at infinity of the rational preset; one transfer question with a new function (R9). Misconception feedback and a 3-step hint ladder per exercise (R6, R7). Answers typed with comma or dot, tolerance stated.
- Handwriting: optional, same quick-check pattern as E2 is NOT used here (answers can be -inf, "does not exist"); type or choose only. Phone LAB row (new): knob d, slider a (or x for the infinity preset), through ctx.controls.
States: first run (hole preset, d = 1), undefined value, infinite value, no limit, reduced motion (zoom jumps), canvas not ready.
v2 files: NEW modules/math/limits.js (manifest {id:'limits', subject:'math', color:'--math', title:['Limits','Limite de funcții'], order:3.5, tags:['lab','quest']}); the zoom and table engine can start from the projectile / pythagoras files (U.gridMap, U.slider, U.tiles). PROTECTED profile (Plumb): one verse fragment of at most 8 words per item and at most 6 quotations in the whole lesson, 4 chips only (no free typing, no long cloze), and every item also has our own sentence to complete ("In this stanza the poet compares ... to ..."). 5 Argument (BAC essay builder): a prompt in BAC style ("Prezintă ... tema / personajul / ...", text type and wording per the official barem, to be confirmed). Four slots in order: Thesis, Argument 1 with an example from the text, Argument 2 with an example, Conclusion. Each slot offers 3-4 candidate sentences (one fits; the others are off-topic, unsupported or retell the plot) chosen by tap; after all four the checklist shows the barem-style checks (thesis answers the prompt, each argument has a text example, connectors used, conclusion returns to the thesis) as OK / MISS with a reason, plus a free write box (3-5 sentences) that is only self-checked against the same checklist with tick boxes: Lumio has no backend and never claims to grade free text. Score = checks passed (1-3 sparkles by 2, 3, 4 of 4); Lumens +15 on the first full completion.

Sparkles: 3 = no hint and no miss, 2 = exactly one hint or one miss, else 1. Lumens 10 / 15 / 20 by sparkles on first completion only; replay pays 0 and says so; better sparkles saved silently. Wrong answers always show the reason.
Lumens / Moon / hearts: all Lumens through ctx.award, all answers through ctx.report ({qt} = Match 5 + Quote 5 + Argument 4 + Test 8 = 22, {qd}, {ok}, {bad}) so the rating card and ticker work as in the other lessons; Moon is NOT touched by any lesson (Moon moves only through Challenge, wave 2 B); a Challenge counts Lumens gained, so literature Lumens count there.
