## 4 Common contract C (every spec below uses it; builders and Tester read this once)
C1 Pattern: the module is a copy-and-adapt of linear.js (state object ST survives theme / language re-render; stored progress key lumio2_<id> = {v:1, ex:[done indexes]}; load/save inside try/catch; blocked storage = memory only; manifest inside the file; no edit to shell, tokens or other lessons).
C2 Hooks (same as linear): on open ctx.report({qt:4}); when the CURRENT exercise is solved and its index is not in ex: push, save, fx.ok(), ctx.report({qd:ex.length,ok:1}), ctx.award(10), toast "+10 Lumens"; when the 4th is solved also ctx.award(15) and fx.burst(120). First completion only because the index is stored (reload never pays twice). Total 4 x 10 + 15 = 55 Lumens, same as linear and interest (gas 25, projectile levels 10/15/20 = 45). A miss on a typed answer: fx.bad(), ctx.report({bad:1}), targeted message. No Moon.
C3 Exercise record: {q:{en,ro}, kind:'lab'|'type'|'choice', ok(state or value), react(state)->message key or null, h:[h1,h2,h3] (en/ro each)}. Only the CURRENT exercise is checked. Order is fixed. An exercise must not be solved by the start state (R8).
C4 Reactive feedback line (aria-live polite) under the list: if react() returns a message show it, else show the hint level the student asked for. This is the gas pattern (phh_* strings). Every lab exercise has at least 2 react() messages; every typed exercise has at least 3 wrong-answer messages plus a fallback. Counting these is the Tester's measurable check for R6.
C5 Hint ladder (R7): a "Hint" button per exercise cycles 1 nudge, 2 method, 3 worked step (the worked step uses different numbers than the exercise, as projectile does, never the answer itself). Level resets when the exercise changes. Tiny code: counter hn, label "Hint {n}" like projectile lv_hint.
C6 Typed answers: one input (inputmode decimal), Enter or a Check button; parser = num() from linear.js (comma or dot, minus variants normalised, trailing "%" and "°" and unit text ignored, empty = nothing happens); accepted value and tolerance printed under the field ("Accepted: 24.4 ± 0.5"), so the student can see why a value passes (R4, R5). Exact-integer answers: no tolerance. After 3 misses the worked step (hint 3) opens by itself.
C7 Language: EN and RO side by side in the module (S table + exercise records, as linear.js). Comma-below ș ț only (never cedilla ş ţ). Decimal comma in Romanian numbers, dot in English (use ctx.n([".",","]) as projectile does). One word per concept; Lumens = Lumeni, never XP.
C8 Accessibility (R14): every control a native button / input / range; canvas has role img with an aria-label that is re-set on every update (the reading, not "canvas"); meaning never by colour alone (shape, text, dash style); Reduce motion = one static frame (Loop already does it); tokens only; focus ring as the other lessons; target sizes by pointer type as the other labs.
C9 Overview data (optional, inert until the overview feature ships, like linear.js `overview`): each spec gives intro (EN/RO) and 5 takeaways; podcast steps are written by the Professor only when the overview feature ships (not needed for the lesson to ship).
C10 Parity: new lessons have no v1, so the parity table is "N/A, new". Delete-the-registry-line leaves the app working. The registry line is the LAST commit, after Tester PASS.
C11 Tester numeric check: recompute every number in the spec's "Verified numbers" table independently (Python or calculator) before reading any code, then compare with the UI; any difference = FAIL. Accepted boundary values (just inside, just outside the tolerance) must be tried in the UI.

## 6 Cards for candidates 7-12 (specs written only when approved)
7 Logic gates / Porți logice (cs, 4 h, L). Objective: "I can predict the output of AND, OR, NOT and XOR for any inputs and build a half adder." Lab: toggles A and B (buttons with 0/1 text), gate chips, output lamp with the letter 0/1, a truth table whose current row is marked by a rule, not colour. Ramp: predict the output, find inputs for a given output, then wire XOR + AND into a half adder and add two bits (links to lesson 1, so it ships after Binary). Risk: none technical; only wiring layout on mobile.
8 pH scale / Scara pH (chemistry, 4 h, M). Objective: "I can say if a liquid is acidic, neutral or basic and how pH changes by a factor of ten in [H+]." At 25 C: pH = -log10[H+] (mol/L), [H+][OH-] = 1.0e-14, pH + pOH = 14. Lab: slider pH 0-14 (step 0.5), beaker with a printed number on every band (colour is a token ramp, number always printed, no orange or violet), a dilution button (10x water; a strong acid 0.1 mol/L pH 1 goes to pH 2, never past 7). Misconception messages: "pH 3 is just a bit more acidic than pH 4" (it is 10x), "diluting a strong base makes it acidic". Needs a teacher check of the grade and the strong-acid wording.
9 Mirror and reflection / Oglinda și reflexia (physics, 2.5 h as an extra tab of lesson 4, else 4 h, L). Objective: "I can predict the reflected ray and where the image in a flat mirror appears." Law: angle of incidence = angle of reflection, both measured from the normal; image is as far behind the mirror as the object is in front. Lab: rotate the mirror with a slider (0-45 degrees, step 5): the reflected ray turns by twice the mirror angle (transfer question). Reuses the ray canvas of lesson 4, so it is cheaper after it.
10 Balancing equations / Echilibrarea ecuațiilor (chemistry, 5 h, M). Objective: "I can balance a simple reaction by changing coefficients only and check each atom count." Lab: steppers for coefficients 1-9, live atom counts per element left and right as numbers with a check or cross word. Exercises: H2 + O2 -> H2O (2, 1, 2), N2 + H2 -> NH3 (1, 3, 2), CH4 + O2 -> CO2 + H2O (1, 2, 1, 2), transfer C3H8 + O2 -> CO2 + H2O (1, 5, 3, 4). Rule: smallest whole numbers (one answer); targeted message when a student would change a subscript ("H2O2 is hydrogen peroxide, a different substance").
11 Bubble sort / Sortare prin interschimbare (cs, 5 h, M). Objective: "I can predict how many swaps bubble sort needs and say why." Lab: 6 bars with numbers, Step button, adjacent compare marked by a bracket and text "compare 3 and 1". Name the exact variant: swaps of adjacent out-of-order pairs; the number of swaps equals the number of inversions (list [4,3,1,2]: inversions (4,3),(4,1),(4,2),(3,1),(3,2) = 5 swaps; [1,2,3,4] = 0). Typed predictions use swaps, never "passes" (variant dependent). Risk: step animation state; Reduce motion = jump.
12 The cell / Celula (biology, 5 h, L). Objective: "I can name the main organelles of an animal and a plant cell and say what each does." Lab: labelled diagram, tap an organelle to see a one-line function, then match function to name (4 exercises), plant vs animal toggle (cell wall, chloroplast, large vacuole). Lowest ranked: mostly memorising, little experiment, and the drawing needs the most art. Build only if time remains.
